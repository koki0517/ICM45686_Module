# ICM-45686 モジュール用 KiCad ライブラリ

このリポジトリの `ICM-45686.kicad_pcb` を他の基板に実装するためのライブラリです。KiCad 9形式です。

## 構成

シンボルとフットプリントは **ICM45686_Module** の1種類です。母基板にハンダ付けした1×4・2.54 mmピンソケット2本へ、裏面にピンヘッダー2本をハンダ付けしたICM基板を挿入する構成です。

1つのフットプリントに、母基板のソケット用8パッドとモジュールの外形を含めています。割り当て済みの3D表示には、**母基板側のピンソケット・ICM基板側のピンヘッダー・部品付きICM基板をすべて含めています**。

センサー面を上にして母基板の表面に取り付けます。シンボルのFootprint欄は `ICM45686_Module:ICM45686_Module` に設定済みです。元のモジュールPCBのコネクタ配置・3D設定は変更していません。実装時にモジュール側ピンヘッダーを裏面に取り付けてください。

- `ICM45686_Module.kicad_sym`: 8端子のモジュールシンボル
- `ICM45686_Module.pretty/ICM45686_Module.kicad_mod`: 母基板用フットプリント
- `ICM45686_Module.3dshapes/ICM45686_Module.step`: 色付きの組立STEP（KiCad表示・機械CAD共用、3Dモデルはこの1個のみ）
- `preview/`: 3D配置確認画像、シンボルSVG
- `scripts/generate_library.py`: 元PCBからの再生成スクリプト（Linux、KiCad 9・標準3Dライブラリ・CadQuery 2.6以降が必要）

## 他プロジェクトへの登録

1. `library` フォルダをコピーします。
2. 回路図エディターの「シンボルライブラリを管理」で `ICM45686_Module.kicad_sym` を追加します。ライブラリ名は **ICM45686_Module** にします。
3. PCBエディターの「フットプリントライブラリを管理」で `ICM45686_Module.pretty` を追加します。ライブラリ名は同じく **ICM45686_Module** にします。
4. KiCadの「パスを設定」で **ICM45686_MODULE_DIR** を追加し、コピー先の `library` フォルダの絶対パスを指定します。3Dモデルはこのパスを使います。
5. `ICM45686_Module:ICM45686_Module` シンボルを配置します。

本リポジトリにはライブラリテーブルとプロジェクト変数を登録済みです。他プロジェクトでは上記の登録を行ってください。

## ピン対応

原点はJ1-1（3V3）です。モジュールのセンサー面を上から見た向きをそのまま親基板の表面フットプリントに使用します。PCB座標ではXが右、Yが下です。J1/J2の番号が重複するため、ライブラリではJ2を5～8に置き換えています。

| ライブラリ端子 | 元基板端子 | 信号 | X [mm] | Y [mm] |
|---|---|---|---:|---:|
| 1 | J1-1 | 3V3 | 0 | 0 |
| 2 | J1-2 | GND | 0 | 2.54 |
| 3 | J1-3 | SCLK | 0 | 5.08 |
| 4 | J1-4 | MISO | 0 | 7.62 |
| 5 | J2-1 | INT | 10.16 | 0 |
| 6 | J2-2 | FSYNC | 10.16 | 2.54 |
| 7 | J2-3 | MOSI | 10.16 | 5.08 |
| 8 | J2-4 | CS | 10.16 | 7.62 |

電源は元回路図に合わせて3.3 V入力です。SPI用シンボルとして入出力方向を設定しています。

## 寸法・3Dの想定

- 外形：13.716 × 12.700 mm、角R 1 mm。下辺中央の半円切り欠き（R 0.9144 mm）も元PCBから転写。
- 2.54 mmピッチ、列間隔10.16 mm、ドリル径1.0 mm、パッド1.7 × 1.7 mm。
- 元PCB外形は `F.Fab` と `Dwgs.User` に表示。親基板を切り抜かないように `Edge.Cuts` は使用していません。
- `F.CrtYd` はモジュール全体の投影外形を囲います。基板下に部品を配置する場合は高さも確認してください。
- 3DはKiCad標準のソケット本体8.50 mmとヘッダー樹脂部2.54 mmを組み合わせ、親基板表面からモジュール裏面まで11.04 mmを想定。実際の購入部品の高さ・挿入深さに合わせて調整してください。
- STEPにはICM-45686、コンデンサ3個、基板外形と穴、両側のコネクタを含めています。
- 機械CAD用の組立STEPは親基板用パッドも含むKiCad出力です。出力座標の親基板表面はZ=1.595 mmです。KiCadのSTEP出力後、`scripts/color_step.py` で部品の元の材料色と基板のレイヤー色を復元しています。以前のSTEP参照でも色付き表示が可能です。基板のレイヤー色は設定した色です。フットプリントはこのSTEPのみを参照し、Zオフセットは-1.595 mmです。
- STEPのXY原点はJ1-1で、Y軸はKiCadの3D座標に従いPCB座標と逆向きです。プレビューの親基板は配置確認用で、STEPに親基板本体は含めていません。

## 再生成

リポジトリのルートで実行します。

```bash
# KiCad pcbnewが使えるPythonで実行し、CadQuery環境のPythonパスを指定
/usr/bin/python3 library/scripts/generate_library.py --cadquery-python /path/to/cadquery-env/bin/python
kicad-cli sym export svg -o library/preview library/ICM45686_Module.kicad_sym
```

基板単体などの中間モデルは一時フォルダで生成し、ライブラリには残しません。

元PCBのピン位置や外形を変更した場合は、スクリプトの原点・端子配置・コートヤードも見直してください。

3Dモデルの出典とライセンスは [3dshapes/README.md](ICM45686_Module.3dshapes/README.md) を参照してください。

## 配置済みフットプリントが灰色のままの場合

ライブラリの変更は配置済みフットプリントへ自動反映されません。コピー先の `library` フォルダを最新ファイルに更新し、PCBエディターの「ツール → ライブラリからフットプリントを更新」で対象を更新してください。3Dビューを閉じて開き直し、モデルを再読み込みします。3Dプロパティで `ICM45686_Module.step` を参照している場合も、今回の色付きSTEPにファイルを更新すれば色が出ます。
